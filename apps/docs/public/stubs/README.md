provider API key is configured. All files are locally generated, public-domain content.

| File           | Origin                                                                            |
| -------------- | --------------------------------------------------------------------------------- |
| `image-1.webp` | Generated gradient placeholder (Wave 2), no external source.                      |
| `image-2.webp` | Generated gradient placeholder (Wave 2), no external source.                      |
| `video-1.mp4`  | Generated 1s solid-color clip (Wave 2, ffmpeg `lavfi color`), no external source. |
| `speech-1.mp3` | Generated 1s silence (ffmpeg `lavfi anullsrc`, 44.1kHz mono), no external source. |
| `sfx-1.mp3`    | Generated 1s silence (ffmpeg `lavfi anullsrc`, 44.1kHz mono), no external source. |
| `music-1.mp3`  | Generated 1s silence (ffmpeg `lavfi anullsrc`, 44.1kHz mono), no external source. |
