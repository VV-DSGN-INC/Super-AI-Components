# Changelog

Every pull request that has landed on `main`, newest first. The registry has no versioned releases:
shadcn copies source into the consumer's app, so a change never affects an installed component,
only new installs. This page therefore tracks the branch directly, one entry per merged PR.

Maintenance rule: the PR that merges adds its own line here. An entry is the PR number and the PR
title. The judgment lives in the PR body and the specs it links, not in this list.
