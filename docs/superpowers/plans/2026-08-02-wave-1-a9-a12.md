# Wave 1 primitives (A9–A12) Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Complete the primitive layer — `entity-row`, `section-header`, `reset-affordance`, `stat-readout` — plus the additive `field-row` retrofit, and correct the fan-out table the audit disproved.

**Architecture:** Four independent primitives following the conventions settled by `preview-tile`: `data-slot` attributes, `cn()` from `@/lib/utils`, semantic shadcn variables only, button-semantics-only-when-interactive, named exports, co-located vitest tests. No npm dependencies.

**Spec:** [`2026-08-02-wave-1-primitives-design.md`](../specs/2026-08-02-wave-1-primitives-design.md) — APIs are defined there in §3 and are not duplicated here.

**Build order is forced by dependencies:** A9 → A12 → A11 (+ A6 retrofit) → A10. A11's group-level variant attaches to A12, so A12 must exist first.

## File structure

Per component `<name>`, four files plus two wiring points — the pattern established by `preview-tile`:

| File | Note |
| --- | --- |
| `apps/docs/registry/super-ai/<name>.tsx` | the primitive |
| `apps/docs/registry/super-ai/<name>.test.tsx` | co-located tests |
| `apps/docs/components/demos/<name>-demo.tsx` | docs demo |
| `apps/storybook/src/components/super-ai/<name>.tsx` + `demos/<name>-demo.tsx` + `src/stories/super-ai/<Name>.stories.tsx` | Storybook copies (it copies, not aliases) |
| `apps/docs/lib/catalog.ts` | catalog entry |
| `apps/docs/app/components/[name]/page.tsx` | demo import + map entry |
