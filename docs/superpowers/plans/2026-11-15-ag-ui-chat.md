# AG-UI chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `ag-ui-chat`, a `registry:lib` item that turns AG-UI messages into props for `chat-shell`, `permission-prompt` and `agent-presence`. Fix two `permission-prompt` gaps. Rebuild the `/copilotkit` demo on the new item.

**Architecture:** The spike's `adapter.ts` becomes a protocol-level lib file that depends only on `@ag-ui/core` and React and imports no sibling registry item. CopilotKit stays in `apps/docs` as the demo's client and runtime. `permission-prompt` gains "every dismissal answers" and "arguments follow the call until editing starts".

**Tech Stack:** Next 16, React 19.2, TypeScript, Base UI `AlertDialog`, Vitest and Testing Library, Playwright, `@ag-ui/core` 1.0.2, CopilotKit 1.87.0 (demo only).

**Spec:** `docs/superpowers/specs/2026-11-15-ag-ui-chat-design.md`

## Global Constraints

- Node: run every command with `PATH=/opt/homebrew/opt/node@24/bin:$PATH` (the default `node` is broken; the repo pins 24).
- `ag-ui-chat.tsx` imports only `@ag-ui/core` (types) and `react`. Never `@copilotkit/*`, `@ag-ui/client`, `rxjs` or another `@/registry/...` file.
- Manifest entry, written by the main session only (never a subagent): `{ name: "ag-ui-chat", title: "AG-UI chat", status: "shipped", shadcn: [], npm: ["@ag-ui/core"], target: "lib/ag-ui-chat.tsx" }`.
- CopilotKit and the pins (`@ag-ui/client` and `@ag-ui/core` 1.0.2, `rxjs` 7.8.1) stay in `apps/docs/package.json` only.
- `permission-prompt` declared states stay `allow-once`, `always-allow`, `deny`, `edit-first`. The a11y and story-coverage baselines never grow.
- Never hand-edit `.meta.json`, `index/components.toon` or `public/llms*`; run `pnpm contract:emit`. Run `pnpm build:registry` after any registry change and commit what the generators write.
- Token gate rules apply: no raw colours, no `text-muted-foreground` on a muted surface, write `GH-1234`, not a hash and number, in registry sources.
- Copy: no em dashes, no exclamation marks. The page states that the agent is scripted, no model is called, and "Always allow" approves once.
- `/copilotkit` keeps `robots: { index: false }` and stays out of the nav, like `/generated-chat`.
- Branch per task, never `main`. Nothing is pushed or deployed without Nick's yes.

## Review Focus

1. **The run is stopped while a gated call's arguments are still streaming.** The composer must not stay locked by a call that can never be answered. `pendingToolCall` skips a call whose `function.arguments` is not complete JSON (Task 1).
2. **A user message whose `content` is a part array**, not a string. Its text parts show as the user turn's text (Task 1).
3. **An assistant message with no text and no tool calls** (an empty placeholder mid-stream). It draws no empty bubble and does not split the reply into two turns (Task 1).
4. **The parent sets `open` to false itself** (a controlled close, not the human's). That is not a refusal, so `onDeny` does not fire (Task 2).
5. **An edited approval naming only unknown run ids.** Nothing is retried and nothing is spent (Task 4).

**Interfaces:**

- Consumes: `Message`, `ToolCall` from `@ag-ui/core`.
- Produces:
  - `type AgUiTurnPiece = { kind: "text"; id: string; text: string } | { kind: "tool"; id: string; call: ToolCall; result?: Extract<Message, { role: "tool" }> }`
  - `interface AgUiTurn { id: string; role: "user" | "assistant"; pieces: AgUiTurnPiece[] }`
  - `type AgUiPresence = "needs-you" | "idle" | "acting" | "watching"`
  - `toTurns(messages: Message[]): AgUiTurn[]`
  - `pendingToolCall(messages: Message[], gated: readonly string[] | ((call: ToolCall) => boolean)): ToolCall | undefined`
  - `presenceFor(input: { running: boolean; awaitingApproval: boolean; acting?: boolean }): AgUiPresence`
  - `useAnswerOnce<T>(respond: ((value: T) => unknown) | undefined): (value: T) => void`

  - `pendingToolCall` finds an unanswered call by name list `["retry"]` and by predicate `(c) => c.function.name === "retry"`, and returns `undefined` once a `role: "tool"` message answers it.
  - With two unanswered gated calls, it returns the later one.
  - It skips a gated call whose `function.arguments` is `'{"runIds":["r1"'` (Review Focus 1).
  - A user message with `content: [{ type: "text", text: "What failed" }, { type: "text", text: "overnight?" }]` becomes one user turn whose text piece is `"What failed overnight?"` (Review Focus 2).
